Abstract

Privacy-focused social media platform prioritizing user data protection and control.

Keywords: Privacy, Social Media, Backend

1. Overview

A privacy-focused social media platform built with user data protection and control at its core. It is designed to give users full ownership of their data while keeping them socially connected.

The backend is written in Rust; the web and desktop clients use React and Tauri. Group state is protected with MLS, and clients reach the server over WebSockets or WebTransport, with WebRTC for direct peer-to-peer paths.
