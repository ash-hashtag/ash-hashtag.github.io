01 / Privacy · End-to-end encryption

Lupyd

Privacy-focused collaboration platform with end-to-end encryption, where the server relays and stores data it cannot read.

Visit Lupyd ↗ Ask me about it

clients · rust core · direct peer paths

A privacy-focused collaboration platform with end-to-end encryption. Teams and communities talk, share and work together, and the content is encrypted on their devices before it leaves them, so the server routes and stores ciphertext it cannot read.

The backend is written in Rust; the web and desktop clients use React and Tauri. Group state is protected with MLS, and clients reach the server over WebSockets or WebTransport, with WebRTC for direct peer-to-peer paths.
