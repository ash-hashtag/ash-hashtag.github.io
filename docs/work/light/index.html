Light

draft-tene-light

Abstract

Lightweight WebRTC-based RPC library for building peer-to-peer sync engines.

Keywords: WebRTC, RPC, Sync Engines

1. Overview

Light is a lightweight RPC layer built on WebRTC, for sync engines that need direct, real-time communication between peers rather than a round trip through a server.

     Peer A                                       Peer B
  +-----------+         RTCDataChannel         +-----------+
  |   sync    |------- call(id, method) ------>|  handler  |
  |  engine   |<------ result(id, value) ------|           |
  +-----------+                                +-----------+
        \                                            /
         \______ signaling, only to connect ________/
