draft-tene-firefly

Abstract

End-to-end encrypted chat suite using libsignal and Message-Layer-Security with multi-device support.

Keywords: Security, Encryption, Backend

1. Overview

An end-to-end encrypted chat suite implementing libsignal and Message Layer Security (MLS). It supports multiple devices per user, so a conversation follows its participants across platforms without the server ever holding readable messages.
