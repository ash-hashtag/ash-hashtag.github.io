Abstract

Project demonstrating the benefits of using PostgreSQL over QUIC protocol.

Keywords: PostgreSQL, QUIC, Performance

1. Overview

A project that shows the performance and reliability benefits of running the PostgreSQL protocol over QUIC instead of TCP.

QUIC folds the transport and TLS 1.3 handshakes into one round trip, multiplexes independent streams without head-of-line blocking, and lets a connection survive a change of network address.

  TCP + TLS 1.3                      QUIC
  client          server             client          server
    |---- SYN ------->|                |-- Initial ----->|
    |<--- SYN/ACK ----|                |<- Handshake ----|  1 RTT
    |---- ClientHello>|                |-- query ------->|
    |<--- ServerHello-|  2 RTT
    |---- query ----->|
