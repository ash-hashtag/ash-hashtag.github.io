Abstract

This memo supplements RFC 0 with a description of its author: where the work has happened, what it was built with, and where the author learned to build it.

1. Background

The author moves between product thinking and low-level engineering. Good software should feel obvious; the engineering behind it rarely is.

The interesting part is the difficult middle: turning an ambitious product idea into a system that stays fast, safe and understandable. That has led from encrypted social infrastructure and WebRTC to audio processing, GPU workloads, mobile apps and programming-language experiments.

2. Experience

Lupyd Media (2023 - present)
Founder, full-stack developer. Building a privacy-focused social and collaboration platform from the ground up. Rust across the backend, React and Tauri across the clients, with MLS, blind signatures, WebSockets, WebTransport and WebRTC in the mix.
Turing (2025)
Rust LLM trainer, contract. RLHF training for Anthropic models, bringing systems-level Rust judgment into model evaluation and improvement.
Jandas Corporation (2022 - 2023)
Mobile application developer, contract. Cross-platform Flutter applications, and a low-level audio-processing product spanning Dart and C++.
Freelance (2021 - 2022)
Independent developer. Rust smart contracts, WGPU parallel-processing scripts, automation bots, games and mobile applications.
