How I build

Written the way protocol specs are, because they're meant to be just as binding. Key words per RFC 2119.

  1. 01

    Software MUST NOT collect user data merely because it can be collected.

  2. 02

    Software SHOULD encrypt end to end. The server is not a trusted party.

  3. 03

    Software SHOULD remove any round trip that can be removed.

  4. 04

    Software MAY add a dependency when it pays rent.

  5. 05

    Software MUST stay understandable to whoever maintains it next.
